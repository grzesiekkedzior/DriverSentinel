Documentation

DriverSentinel is a C++20 / Qt 6 desktop application for static inspection of Portable Executable files. It uses LIEF to parse PE structures and Capstone for disassembly.

File compatibility

The application has been tested primarily with:

  • .exe — Windows executables
  • .dll — dynamic-link libraries
  • .sys — Windows kernel drivers

Other PE/COFF-based formats such as .scr, .ocx and .efi may also be compatible, but support for those formats has not yet been fully validated.

Analysis modules

Current modules include:

  • General file information
  • DOS Header
  • COFF File Header
  • Optional Header
  • Sections
  • Imports and function information
  • Strings
  • Certificates
  • Resources
  • Relocations
  • Exception information
  • Debug information
  • Rich Header
  • Capstone-based disassembly

The Imports and Strings views can be exported to TXT, PDF, CSV and JSON.

Architecture Overview

DriverSentinel follows an MVC-like architecture with a clear separation between parsed data, Qt models, application logic and the main UI.

Data

Data structures store information extracted from the analyzed PE file. They are kept separate from presentation logic so the same parsed information can be consumed by models and controllers.

Models

Qt models expose structured data to table and tree views. Larger datasets are presented through model/view classes rather than being embedded directly in UI widgets.

Controllers

Controllers coordinate parsing, model updates and interaction with the user interface. Expensive operations can be moved away from the main GUI thread to keep the interface responsive.

Utilities

Shared helpers contain reusable operations such as formatting, conversions, export functions and binary-analysis support code.

MainWindow

MainWindow coordinates the controllers and presents the individual analysis modules as a single desktop application.

Simplified architecture

Safety note

Unknown or potentially malicious binaries should be analyzed only in an appropriately isolated environment. DriverSentinel is a static-analysis aid, not a substitute for sandboxing or a complete malware-analysis environment.
