File compatibility

PE first. Extension second.

DriverSentinel focuses on the binary structure itself. The formats below are the ones currently validated most thoroughly.

Tested
.exe

Windows executable

Regular user-mode PE applications.

.dll

Dynamic-link library

PE libraries, exports, imports and metadata.

.sys

Kernel driver

Windows driver binaries and PE structures.

Additional compatibility
.scr

Screen saver

Parses as a PE executable.

.ocx

ActiveX control

PE-based COM/ActiveX binary.

.efi

UEFI binary

PE/COFF parsing works, but support is not fully validated.

Additional formats can be parsed in at least some cases, but may expose limited or format-specific information. They are not yet considered fully validated.

Analysis modules

One interface. Multiple layers of a PE file.

Move from high-level metadata to the structures and machine code that explain how the binary is built.

01

PE Headers

DOS, COFF File Header and Optional Header with entry point, image base, subsystem and alignment.

02

Imports

Inspect imported DLLs, functions and dependencies used by the analyzed binary.

03

Sections

Review names, virtual addresses, sizes, permissions and PE characteristics.

04

Disassembly

Inspect machine instructions directly in the UI using the Capstone disassembly engine.

05

Strings

Extract ASCII and Unicode strings useful during static analysis and initial triage.

06

Certificates

Inspect signer, issuer and validity information stored in digital signatures.

07

Resources & Debug

Explore embedded resources, version metadata, Debug Directory data and the Rich Header.

08

Relocations & Exceptions

Inspect relocation blocks and exception-related structures in the image.

Export

Imports and Strings can be exported to TXT, PDF, CSV and JSON.

Workflow

From file to low-level evidence.

01

Open a PE file

Load an executable, DLL or driver and let LIEF parse the underlying PE structures.

02

Inspect structure

Navigate headers, sections, imports, resources, certificates and metadata.

03

Follow evidence

Use strings, dependencies, entry point and section properties to decide where to look next.

04

Read machine code

Move into Capstone-based disassembly when structural information is not enough.

Use cases

Built for learning, inspection and reverse engineering.

DriverSentinel is a static-analysis aid. It is useful when you need a structured view of a PE file before moving to a debugger, sandbox or more specialized reverse-engineering workflow.

Under the hood

Native C++ architecture.

DriverSentinel uses an MVC-like design that separates parsed data, Qt models and application logic. LIEF handles PE parsing while Capstone provides disassembly.
