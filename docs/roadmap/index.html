DriverSentinel Roadmap

DriverSentinel is currently in 0.0.1-beta. This page tracks completed PE inspection modules and the next areas planned for development.

Available now

  • General PE information — path, size, timestamps and version metadata
  • Certificates — signer, issuer and certificate validity information
  • Imports — imported DLLs and functions
  • Strings — ASCII and Unicode extraction
  • DOS Header — legacy DOS header fields
  • File Header — COFF header information
  • Optional Header — entry point, image base, subsystem and alignment
  • Sections — section addresses, sizes and characteristics
  • Disassembly — Capstone-based machine-code inspection
  • Rich Header — Microsoft Rich Header information
  • Debug information — PE Debug Directory data
  • Exception information — exception-related PE structures
  • Relocations — relocation blocks and entries
  • Resources — embedded resources and metadata
  • Export — Imports and Strings to TXT, PDF, CSV and JSON

Format validation

Fully tested first:

  • .exe
  • .dll
  • .sys

Additional PE/COFF formats under validation:

  • .scr
  • .ocx
  • .efi

These additional formats can already be parsed in at least some cases, but they are not yet considered fully validated.

Planned

  • Built-in hex viewer / editor
  • Entropy measurement
  • Extended PE heuristics and analysis
  • Better validation of additional PE/COFF formats
  • Additional reverse-engineering-oriented inspection features
